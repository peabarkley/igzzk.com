# IGZZK · Instagram Knowledge Base

Instagram official docs, translated into plain English.

**Live site:** https://igzzk.com

## What this is

A static knowledge base that translates Instagram's Help Center, Business Tools documentation, and official product announcements into plain English. No jargon. No rumours. No made-up "insider tricks".

## Sections

- **Algorithm Decoded** — Feed, Reels, Stories, and Explore ranking signals
- **How to Post** — Feed, Reels, Stories, Instants specs and best practices
- **Business Tools** — Insights, Promote, Shopping, Meta Business Suite
- **Pitfalls to Avoid** — account recovery, original content rules, scams

## Tech stack

- Pure HTML + CSS + vanilla JavaScript
- No build step, no framework, no dependencies
- Hosted on GitHub Pages
