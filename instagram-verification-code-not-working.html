Instagram verification code not working? Fix it

5 min readUpdated September 2026

You're trying to log in. Instagram says it sent a code. Nothing arrives. This is one of the most frustrating account issues because you're locked out with no obvious fix.

The cause is usually one of five things. Work through them in order.

1. Check if your contact info is outdated

If you changed your phone number after creating your account, Instagram may still be sending codes to the old one [citation:3].

  • Open Instagram (if you can) and tap your profile.
  • Tap the three-line menu → Accounts Center.
  • Go to Personal details → Contact info.
  • Check if your phone number is current. If not, add the correct one [citation:3].

2. Check if you've blocked Instagram's number

Many people have accidentally blocked the number Instagram uses to send SMS codes. The number is typically 32665 or 32099 [citation:3].

Go into your phone's blocked numbers list and unblock it. This is an odd phenomenon, but it's a real and common cause [citation:3].

3. Check your phone settings

  • Airplane mode off? Make sure it's disabled [citation:3].
  • Mobile data enabled? Some SMS apps need it [citation:3].
  • Signal strength? Move to an area with better reception.

4. Try a different verification method

On the screen asking for the code, look for "Try another method" [citation:5][citation:14].

  • Backup codes: If you saved them when enabling 2FA, choose "Use backup code" [citation:5][citation:14].
  • Email instead of SMS: Instagram may offer to send the code to your registered email instead.
  • WhatsApp: If your number is linked to WhatsApp, Instagram can send the code there.

5. Check if Instagram is down

If Instagram's servers are having issues, codes may be delayed across the board. Check a service like DownDetector. If it's a widespread outage, the only fix is waiting [citation:3].

If nothing works

Instagram may have temporarily blocked code delivery after too many attempts. This is a security measure [citation:3]. In that case:

  • Wait 24 hours before trying again.
  • Try logging in from the same device and network you normally use.
  • Temporarily turn off any VPN — Instagram blocks VPN connections [citation:3].

What to do with this

Check your contact info first, then check if you've blocked Instagram's number (32665 or 32099). If you have backup codes saved, use them. If you're still stuck, wait 24 hours and try again from your normal device and network.
