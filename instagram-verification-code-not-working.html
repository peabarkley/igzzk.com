Verification code not working? How to fix it

3 min readUpdated November 2026

Instagram uses two different messages that people both call a verification code. One is the login code for two-factor authentication. The other is the password-reset email. The fix depends on which one failed.

Menu names are in the middle of a change. Instagram says you may see either Accounts Center or Meta Account settings. View source ↗

If this is a two-factor login code

When you turn on two-factor authentication, Instagram asks you to choose text message (SMS) codes or a third-party authentication app. View source ↗

  • Text message. If SMS is the method, Instagram sends a 6-digit security code each time someone tries to log in from a device it does not recognize. SMS two-factor authentication requires a confirmed phone number. The number you enter while turning it on becomes the confirmed number. The setup screen also offers WhatsApp next to SMS. View source ↗
  • Authentication app. An app such as Duo Mobile or Google Authenticator generates the login code Instagram uses when you log in from a new device for the first time. You have to be logged in to turn this on. View source ↗

If two-factor authentication is already on and a code cannot be sent because of connectivity or delivery issues, Instagram says you can still finish logging in with a backup code. View source ↗

Open your backup codes

You have to be logged in to see the list or to replace it. Instagram's published path is:

  1. Click More in the bottom left, then click Settings.
  2. Click Accounts Center, then click Password and security.
  3. Click Two-factor authentication, then click the account.
  4. Click Additional methods.
  5. Click Backup codes.

Copy the codes, take a screenshot, or save them another way, so they are available the next time you log in. To cancel the current codes and get a new set, open the same list and click Get new codes. View source ↗

Changing the phone number that receives SMS codes also ends on a list of backup codes. Instagram tells you to save them so you can get in if you lose the device or have trouble with another security method. Not everyone can open that setting in Accounts Center or Meta Account settings yet. The same Help Center page includes an in-app path. View source ↗

If you cannot log in, and you have no saved codes

The backup-code list is only available while you are logged in, so a logged-out login screen cannot open it. Instagram's login help covers a forgotten password, email problems, an identity check, and a hacked account. View source ↗

If you think someone else has the account, use Instagram's hacked-account steps. View source ↗

If the missing message is a password-reset email

That email is separate from a two-factor code. Instagram says it may be missing because:

  • It landed in spam.
  • The email address was mistyped when the account was created. If that happened, Instagram says it cannot give you access to the account.

Instagram's suggestions are to check spam, reset through Facebook if the Instagram and Facebook accounts are linked, and ask your email provider to accept mail from the @instagram.com domain. View source ↗

What to do with this

If a two-factor code cannot be sent, use a backup code you already saved. If you are still logged in somewhere, open Additional methods and save the list before you need it. If the missing message is a password-reset email, check spam and the address on the account. If you are locked out with no saved codes, use Instagram's login help.
